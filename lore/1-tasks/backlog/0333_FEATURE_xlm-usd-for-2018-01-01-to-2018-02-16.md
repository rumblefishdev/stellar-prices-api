# XLM/USD for 2018-01-01 → 2018-02-16

## Summary

[[0331]] prices pre-2021 candles from an hourly XLM/USD series loaded into
`prices.usd_rate`. The series prepared there starts at 2018-02-16 23:00 UTC.
The 47 days from 2018-01-01 to 2018-02-16 have no rate, so their XLM-quoted
candles stay at `close_usd = 0`. This task finds a rate for those days and
loads it in the same shape as the rest of the series.

## Context

- **Why the series stops there.** The exchange API the 0331 series was built
  from cannot reach trades before 2018-02-16 23:03: a time-based `since`
  anywhere from 2017-12 to 2018-02-16 lands on that first reachable trade, and
  paging from the start jumps to it after the first 1,000 trades. Probed
  2026-10-14.
- **The market did trade then:** about 1,000 trades a day around 2018-01-01.
- **How the data will be handled is not decided.** The source and its terms
  of use are still open (see 0331).

## Options

1. The same exchange's downloadable historical OHLCVT files, which cover the
   period. They have to be fetched by hand.
2. The on-chain estimate from 0331's research: dollar tokens plus CNY/XCN/HKDT/
   EURT tokens at ECB reference rates, with a depeg guard and a smoother.
   The on-chain witnesses (CNY, EURT, XCN) trade from 2018-01, so this is
   possible for the period. It is not scored there: no ≥ 2-exchange truth
   before 2018-05.
3. Leave the 47 days unpriced and say so in the API description.

## Implementation Plan

1. Pick the option and record why.
2. Build the hourly series for 2018-01-01 00:00 → 2018-02-16 22:00 UTC and
   keep its provenance (file, hash, date).
3. Check the seam against the 0331 series from 2018-02-16 23:00 onward.
4. Insert in the same shape as 0331's rows (`('native','XLM','','')`, staged
   method first, same verify queries), then promote together with them.
5. Re-run 0331's coarse-repair step for 201801–201802 on every tier.

## Acceptance Criteria

- [ ] Source chosen and recorded, with its terms of use.
- [ ] Hourly XLM/USD rows for every hour of 2018-01-01 → 2018-02-16 that has a
      rate, provenance recorded.
- [ ] Agreement with the 0331 series on the overlap recorded (median and max
      deviation).
- [ ] XLM 1d candles for 2018-01-01 → 2018-02-16 return a USD price, or the
      gap is documented if option 3 is chosen.
